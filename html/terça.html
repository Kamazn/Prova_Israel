Assunto da Prova

Modelagem de Banco de Dados: é utilizada para representar e organizar os dados antes da criação do banco.

A sigla MER significa Modelo Entidade Relacionamento.

O BRModelo é uma ferramenta utilizada para criar modelos de banco de dados de forma visual.

Conceito apresentado durante as aulas de Modelagem de Banco de Dados.

Durante a modelagem, devemos evitar criar entidades sem analisar o problema, mas devemos identificar corretamente entidades, atributos, relacionamentos e cardinalidades.
