Assunto da Prova

Linguagem C: é uma linguagem de programação utilizada para desenvolver programas através de comandos e estruturas.

A função stdio é utilizada através da biblioteca stdio.h para trabalhar com entrada e saída de dados.

A Linguagem C permite criar programas utilizando variáveis, condições, repetições e entrada de dados.

Conceito apresentado durante as aulas de Linguagem C.

Durante a programação, devemos evitar escrever códigos sem organização, mas devemos utilizar comandos simples e organizar corretamente o programa.
