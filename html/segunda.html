Assunto da Prova

HTML:Linguagem de Marcação de Hipertexto é a linguagem padrão usada para criar e estruturar páginas na internet.

A sigla HTML significa HyperText Markup Language.

HTML é uma linguagem de marcação utilizada para estruturar o conteúdo de uma página.

Conceito apresentado por Israel durante as aulas de HTML.

Antes, algumas pessoas utilizavam tags antigas para organizar visualmente a página,mas atualmente devemos utilizar tags semânticas para organizar melhor o conteúdo.
