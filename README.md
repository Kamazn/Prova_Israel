# Calendário de Provas - Unipê

Este projeto foi desenvolvido para a prova de HTML com o objetivo de criar um site simples para consultar informações sobre provas e realizar agendamentos.

O site possui páginas para visualizar as provas de segunda, terça e quarta-feira, além de uma página com formulário para agendamento.

## Conteúdos utilizados

Durante o desenvolvimento foram utilizadas várias tags HTML, como:

- header
- nav
- main
- section
- article
- aside
- footer
- table
- form
- details e summary
- figure e figcaption
- progress e meter
- video

Também foram utilizados formulários, imagens, vídeos locais e outros recursos que foram pedidos.

## Organização

O projeto está organizado em pastas para arquivos HTML, imagens, áudios e vídeos.
